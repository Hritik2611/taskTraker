# Task Tracker

A simple and efficient Task Management application built using Node.js, Express, and EJS templates. This project provides a clean interface to manage daily tasks seamlessly.

## Features

* **Add Task** – Easily create and add new tasks to your list.
* **Update Existing Task** – Edit and update the details of any current task.
* **Delete Task** – Remove a single task quickly once it is completed.
* **Delete Multiple Tasks** – Select and remove multiple tasks at the same time (Bulk Delete).

## Tech Stack

* **Backend:** Node.js, Express.js
* **View Engine:** EJS (Embedded JavaScript)
* **Database:**  Mongoose

## Getting Started

Follow these steps to get the project running locally on your machine:

### 1. Clone the repository
```bash
git clone <https://github.com/Hritik2611/taskTraker>
cd taskTraker/backend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Configuration
Create a `.env` file in the root directory and add your required environment variables (e.g., Database connection string, Port).

### 4. Run the application
```bash
npm run start
```
